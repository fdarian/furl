# furl

furl is a curl replacement for AI agents: it fetches a URL and returns LLM-optimized markdown.

It works nicely with [LLM-friendly websites](https://is-agentic.com/), and comes with a [set of strategies](/fetch-strategy) that detect whether a website can serve markdown — so nothing needs parsing and the whole thing runs locally.

furl is also configurable and [extensible with plugins](/plugins/overview).

---

### See it in action

:::code-group
<div data-title="furl">
```bash
furl https://eve.dev/
```


## Getting started

### Installation

```bash
brew install fdarian/tap/furl
```

::::details[Also available via npm]

:::code-group

```bash [npm]
npx furl-cli [url]
```

```bash [pnpm]
pnpx furl-cli [url]
```

```bash [bun]
bunx furl-cli [url]
```
:::
::::

### First fetch

```bash
furl [url]
furl https://mintlify.com
furl https://github.com/fdarian/nisi
```

:::code-group
<div data-title='Direct'>
```bash
furl https://mintlify.com
```

Output:
```markdown
# The Knowledge Platform Built for Agents

> [llms.txt](https://www.mintlify.com/llms.txt)

Self-updating documentation for startups, enterprises, and agents.

URL: https://www.mintlify.com
...
```

> Mintlify honors `Accept: text/markdown`, so it served markdown directly.
</div>

<div data-title='Firecrawl (with parsing)'>
```bash
furl https://github.com/fdarian/nisi
```

Output:
```markdown
# nisi

[Permalink: nisi](https://github.com/fdarian/nisi#nisi)

**A simpler way to review code.**

* * *

**What's unique about nisi**:

- Re-review only what changed since you last looked. Every other tool resets 400 lines of a reviewed file when you only added one nit. nisi snapshots your review and diffs from there.
...
```

> A GitHub repo page doesn't serve markdown, so firecrawl handled the parsing.

> :badge[Tip] You can [write your own plugin](/plugins/overview) to intercept `github.com/<org>/<repo>`, route it through the GitHub API, and format the result the way you prefer.
</div>
:::
