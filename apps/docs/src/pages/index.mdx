# furl

`furl` is a curl replacement for AI agents: fetch a URL and return an LLM-optimized markdown representation instead of raw HTML.

## Install

```bash
bun install
```

## First fetch

```bash
bun run apps/cli/src/main.ts https://vercel.com/blog
```

If the target already exposes markdown, `furl` returns it directly; otherwise it retries with `.md` appended. For sites that need more than that, opt into a provider like `jina` with `--plugin jina` — see [How It Works](/how-it-works).
