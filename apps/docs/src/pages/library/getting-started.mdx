`furl-lib` is the engine behind the `furl` CLI, packaged as an [Effect](https://effect.website) library. Give it a URL and it walks the same [resolver chain](/fetch-strategy), returning markdown from the first resolver that can produce it. Use it when your agent or app needs that in-process instead of shelling out to `furl`.

## Requirements

- ESM: load it with `import`, not `require`.
- Node 20 or newer, or Bun.
- Effect v4, 4.1.0 or newer.

## Install

```package-install
npm i furl-lib effect
```

`effect` is a peer dependency, so your app and `furl-lib` share one Effect runtime.

## First fetch

```ts
import { Furl, Resolvers } from 'furl-lib';
import { Effect, Layer } from 'effect';
import { FetchHttpClient } from 'effect/http';

const layer = Furl.layer({ resolvers: Resolvers.defaults }).pipe(
  Layer.provide(FetchHttpClient.layer),
);
const result = await Effect.runPromise(
  Furl.fetch('https://bun.sh/docs.md').pipe(Effect.provide(layer)),
);
console.log(result.source);
console.log(result.markdown.split('\n')[0]);
```

Output:
```text
raw
# Welcome to Bun
```

`Furl.layer` builds the `Furl` service from a list of resolvers. The service makes its requests through an HTTP client, which you provide; `FetchHttpClient.layer` uses the runtime's global `fetch`. `Furl.fetch(url)` is a shortcut for getting the service and calling its `fetch`, so inside an Effect program you can `yield*` it directly and provide the layer once at the edge.

`Resolvers.defaults` is already the layer's default, so `Furl.layer()` is the same thing. It is spelled out here because [Resolvers](/library/resolvers) is where you change it.

### The result

`Furl.fetch` succeeds with `{ markdown, source }`:

| Field | Meaning |
|---|---|
| `markdown` | The page as markdown |
| `source` | The `id` of the resolver that produced it, such as `raw` |

## What it won't do

The default resolvers succeed on URLs that already serve markdown or a plain file. For a page that serves only HTML, the fetch fails with `AllResolversFailed`; add a provider such as `jina` to parse those, as shown on [Resolvers](/library/resolvers).
