---
title: Library
description: Run furl's fetch engine from your own Bun code
---

`@furl/core` runs the same resolver chain as the `furl` CLI inside your own Bun program. It is Bun-only.

- [Getting started](/library/getting-started): install it and make a first fetch.
- [Resolvers](/library/resolvers): choose which resolvers run, and where provider keys come from.
- [Errors](/library/errors): handle the ways a fetch can fail.
