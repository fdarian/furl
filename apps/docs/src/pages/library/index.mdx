---
title: Library
description: Run furl's fetch engine from your own code
---

`furl-core` runs the same resolver chain as the `furl` CLI inside your own program, on Node or Bun. It reads no config file, so what you pass to it is what runs.

- [Getting started](/library/getting-started): install it and make a first fetch.
- [Resolvers](/library/resolvers): choose which resolvers run, supply provider keys, or write your own.
- [Errors](/library/errors): handle the ways a fetch can fail.
