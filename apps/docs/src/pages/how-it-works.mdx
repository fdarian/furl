# How It Works

`furl` resolves markdown by running an ordered list of **resolvers** implemented in `packages/core`. By default that list is three cheap, keyless probes, tried in this fixed order:

## Default chain

1. Extension passthrough

If the URL pathname ends with a file extension, `furl` fetches the body as-is and reports `raw`.

2. Direct markdown request

For non-file URLs, `furl` sends a `GET` with `Accept: text/markdown`. If the response `content-type` contains `markdown`, it returns the body and reports `direct`.

3. `.md` suffix retry

If the direct fetch does not return markdown, `furl` retries the same URL with `.md` appended before any query string. A successful markdown response reports `md-suffix`.

If all three decline, `furl` fails rather than reaching for a provider — see [Opt-in providers](#opt-in-providers).

## Opt-in providers

`jina`, `exa`, and `firecrawl` extract markdown through a third-party API, so they aren't part of the default chain. Add `default:jina` (or `default:*` for all six built-ins) to your config `order`, or pass `--plugin jina` for a single call:

```bash
furl https://example.com --plugin jina
```

`jina` works without an API key; `exa` and `firecrawl` need one (see [Providers](/providers)).

## Source labels

The CLI writes the markdown body to stdout and a one-line diagnostic to stderr, naming whichever resolver produced the markdown:

```text
↳ via raw
↳ via direct
↳ via md-suffix
↳ via jina
↳ via exa
↳ via firecrawl
```

A plugin that resolves the URL reports its own manifest `name` instead (e.g. `↳ via x`).

## Plugins

The default chain and the opt-in providers above are exactly what the plugin system extends. Each stage is a `default:` built-in (`default:raw`, `default:direct`, `default:md-suffix`, `default:jina`/`default:exa`/`default:firecrawl`, detailed in [Builtins](/plugins/builtins/fetch-strategies)) that can be named in the `order` config; plugins run ahead of them to handle sites the generic chain can't, like client-rendered pages. See [Plugins](/plugins/overview) for the resolution algorithm.
