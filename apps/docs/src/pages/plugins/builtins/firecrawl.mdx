# firecrawl [Structured markdown scraping]

Sends the URL to [Firecrawl](https://firecrawl.dev), which scrapes the page and returns real markdown.

Headings, links, and lists come through intact, so it's the one to pick when the structure of the page carries meaning.

## Enable it

```jsonc [~/.config/furl/config.json]
{
  "order": ["default:*", "default:firecrawl"]
}
```

Or force it for a single call:

```sh
furl https://example.com --plugin firecrawl
```

## Adding a key

Required — without one, firecrawl declines and the chain moves on. furl reads `FIRECRAWL_API_KEY` from the environment first, then falls back to the keychain:

```sh
furl secrets set firecrawl
```

### Further reading

:::details[What furl sends]

`POST https://api.firecrawl.dev/v1/scrape` with `Authorization: Bearer <key>` and a body of `{ "url": url, "formats": ["markdown"] }`. The markdown is read from `data.markdown`.
:::
