First public release of `furl-lib`: the furl fetch engine as a runtime-agnostic Effect library for Node 20+ and Bun, shipped as built ES modules with type declarations. `Effect.runPromise(Furl.fetch(url))` works with no layer and no HTTP client setup (it runs `Resolvers.defaults` over the global `fetch`) and resolves to `{ markdown, source }`, where `source` is the winning resolver's `id`. `Furl.layer({ resolvers })` is the optional way to change the default list; it also takes an `HttpClient` from the context it is built in. Resolvers are plain objects: use `Resolvers.defaults` (`raw`, `direct`, `md-suffix`), add `Resolvers.jina`, `Resolvers.exa` or `Resolvers.firecrawl` with an optional `apiKey` (a string, or an Effect returning an `Option<string>`; the provider's environment variable is read when it is omitted), or write your own, and replace the list for one call with `Furl.fetch(url, { resolvers })`. The library reads no config file, keychain or plugin folder. `effect` is a peer dependency.
